Phần 1.Phân tích.

+ Dùng file Word (.docx) để lưu trên Git: đây là file nhị phân nên GitHub không xem trực tiếp được, và sửa 1 dấu phẩy Git vẫn báo xung đột cả file.
+ Nghĩ Markdown chỉ là chữ thô nên không chuyên nghiệp: thực tế Markdown có tiêu đề, danh sách, bảng, link và hiển thị rất gọn đẹp (ví dụ README.md).Vì sao Markdown an toàn, nhẹ hơn
+ Chỉ chứa chữ nên nhẹ, mở được ở mọi nơi. Git Diff so sánh theo từng dòng nên chỉ ra đúng chỗ sửa. Mất 1 byte: Word hỏng cả file, Markdown chỉ lỗi 1 ký tự.
